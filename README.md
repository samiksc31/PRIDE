# PRIDE

PRIDE is a personal repository housing **LION**, a local AI terminal assistant built to run entirely offline on your machine without needing any cloud API keys. 

Designed specifically for developer workflows, LION helps you write Python code, debug syntax errors, and safely execute terminal commands locally.

---

## What LION Can Do

1. **Python Code Generation** — Writes clean, efficient Python code on demand using local models via Ollama.
2. **Syntax Fixing** — Analyzes faulty code or error traces and automatically provides corrected Python snippets.
3. **Command Execution** — Safely runs terminal and shell commands directly from the workflow session.
4. **100% Local & Private** — Runs via a local model instance, meaning zero API costs, zero tracking, and complete privacy.

---

## Prerequisites

- **Python 3.10+** installed on your system.
- **Ollama** installed locally ([Get Ollama here](https://ollama.com/)).
